# Product Vision

> 「让重要的事，一直留在眼前。」

## 定位（Positioning）

PinNotes 是常驻系统托盘的桌面**置顶便签提醒**应用。它把"重要提醒"钉在屏幕上——每条便签是一个独立的、置顶、无边框、透明的真实 OS 窗口，可拖动定位并记住位置。

## 核心差异化：无法永久隐藏

「隐藏」不是收起，而是 **snooze**：到设定的隐藏时长后，便签会**不抢焦点地弹回原位**，直到被标记「完成」。只有「完成」才让它从桌面消失（进入"已完成"列表，可重新激活 / 复制 / 编辑 / 永久删除）。这让"看一眼就忘"的提醒无法被随手关掉而失效。

## 长期目标（Long-term goal）

成为桌面端**最可靠的提醒方式**：本地优先、零依赖常驻、开机自启、跨平台（Windows 优先，预留 macOS / Linux）。

## 总体范围（Overall scope）

**范围内**：多便签多窗口、拖动定位 + 记忆位置、snooze 重弹、托盘菜单管理、已完成列表、本地 SQLite 持久化、开机自启、中英文 i18n、OTA 自动更新、**便签 Markdown 格式化**（编辑/渲染形态 + 语法子集由 release 0.6.0 的 feature analysis 定稿）。

**范围外（YAGNI，按需再议）**：云同步 / 多设备 / 账号、优先级 / 截止日期 / 定时、富文本（非 Markdown 的所见即所得编辑）、提醒音、多显示器独立布局。
